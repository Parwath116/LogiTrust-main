Frequently Asked Questions

How does the smart contract escrow work?
When a Shipper creates a shipment, escrow funds (converted from ₹ INR to Sepolia ETH using the configured exchange rate) are programmatically locked in the SmartEscrow contract. Funds remain securely locked until the shipment reaches its destination and the Receiver approves the release, or until an Admin resolves a flagged dispute.
What happens when a temperature or humidity breach occurs?
The IoT sensor stream continuously compares ambient conditions with shipment thresholds. If sustained rule breaches occur (e.g. 3 consecutive breaches within 15 minutes), the backend oracle automatically transitions the shipment to disputed and locks the funds. In parallel, the AI service calculates spoilage risk and flags high-risk shipments for Admin review.
Who has the authority to resolve disputes?
Only platform administrators (configured via ADMIN_EMAIL) can access the Admin Console to arbitrate disputed or flagged shipments. The Admin can execute a Force Release to pay the Shipper or a Force Refund to return the escrow to the Receiver.
Is the GPS tracking live hardware or simulated?
LogiTrust supports both! When an Arduino Uno R4 with a TinyGPSPlus module is connected, live satellite fixes are reported (requiring satellites ≥ 4, HDOP < 5). For software demos, a built-in CLI route simulator generates realistic telemetry labeled with a "Simulated location" badge. In all cases, destination arrival is strictly verified server-side via geofencing (within 500m).
Why does LogiTrust use a custodial backend relayer instead of MetaMask?
To provide seamless UX for supply chain operators without requiring browser wallet extensions, seed phrase handling, or direct gas management. The backend oracle wallet submits all on-chain transactions on Sepolia, generating public transaction hashes that can be independently verified on Etherscan.
How does the AI spoilage prediction model work?
A FastAPI microservice runs a Gradient Boosting Pipeline trained on cold-chain degradation patterns across cargo categories (pharma, dairy, produce, electronics, general). It evaluates live temperature differences, spike history, humidity, and transit duration to produce a 0–100% risk score. If risk exceeds 80%, the shipment is flagged for Admin investigation.
